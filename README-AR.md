# بورتفوليو زياد الغامدي

هذه ملفات الموقع الأصلية، جاهزة للتعديل دون تثبيت حزم أو تنفيذ build.

## محتويات المشروع
| الملف | وظيفته |
|---|---|
| index.html | أقسام الصفحة، النبذة، العناوين، البريد وروابط التواصل |
| styles.css | الألوان والخطوط والمسافات وتنسيق الجوال |
| app.js | عرض البيانات، تصفية المشاريع، قائمة الجوال والحركات ونوافذ التفاصيل |
| data.json | المشاريع والخبرات والمهارات والشهادات |
| favicon.svg | أيقونة تبويب المتصفح |

## التشغيل في VS Code
1. فك ضغط الملف أولًا.
2. افتح المجلد zyad-portfolio عبر File → Open Folder في VS Code.
3. ثبّت إضافة Live Server من تبويب Extensions إذا لم تكن موجودة.
4. اضغط بزر الفأرة الأيمن على index.html واختر Open with Live Server.
5. عدّل الملفات واحفظها وشاهد النتيجة في المتصفح.

لا تعتمد على فتح index.html بالنقر المزدوج: تحميل data.json يستخدم fetch ويحتاج خادم HTTP محليًا.

بديل إذا كان Python مثبتًا: افتح Terminal داخل مجلد المشروع وشغّل:

```sh
python -m http.server 5500
```

ثم افتح http://localhost:5500 . على بعض الأجهزة يكون الأمر python3 بدل python.

## أين أعدّل؟
- الاسم والنبذة والبريد وروابط التواصل: index.html.
- المشاريع والخبرات والمهارات والشهادات: data.json؛ احتفظ بصيغة JSON الصحيحة، بعلامات اقتباس مزدوجة ودون فاصلة بعد آخر عنصر.
- الألوان والخطوط: styles.css، وابحث عن :root والمتغيرات اللونية.
- تنسيق الجوال: ابحث في styles.css عن @media.
- ألوان بطاقات المشاريع: مصفوفة palettes في app.js.
- عند زيادة عدد المشاريع أو تقليله، حدّث العدد الظاهر 12 في زر «الكل» في index.html وكذلك النص ' / 12' في app.js؛ العدد المعروض لنتائج التصفية يُحسب تلقائيًا.
- استخدم معرف id مختلفًا لكل مشروع جديد، وحافظ على أسماء الحقول الموجودة.

## معاينة الجوال
من أدوات المطور في المتصفح فعّل محاكاة الأجهزة، وجرّب أكثر من عرض للشاشة بعد تعديلات التنسيق.

## النشر
الموقع ثابت؛ ملفات الموقع الخمسة موجودة مباشرة في المجلد ولا يحتاج أمر بناء. عند استخدام استضافة ملفات ثابتة اجعل هذا المجلد مجلد النشر. يتطلب ظهور الخطوط الخارجية اتصالًا بالإنترنت؛ توجد خطوط بديلة في التنسيق.

تعديل هذه النسخة على جهازك لا يغيّر الموقع المنشور تلقائيًا؛ يلزم رفع النسخة المعدلة لاستضافتك.
